
# Python File Management and Built-in Functions

## Project Structure

- directory_management/
  - create_list_dirs.py
  - move_files.py
- builtin_functions/
  - map_filter_reduce.py
  - enumerate_zip_examples.py

## Description

This project contains Python examples for working with files, directories, and built-in functions.

## Topics

1. Creating and listing directories
2. Moving, copying, and renaming files
3. Using map(), filter(), and reduce()
4. Using enumerate() and zip()

## How to Run

```bash
python directory_management/create_list_dirs.py
python directory_management/move_files.py
python builtin_functions/map_filter_reduce.py
python builtin_functions/enumerate_zip_examples.py
```
